# Exploring London's Travel Network

## Project Overview

This project explores London's public transport network using SQL to analyse passenger journey data.

The analysis focuses on identifying the most popular transport types, investigating Emirates Airline cable car usage, and examining the years with the lowest London Underground and DLR passenger numbers.

## Technologies Used

- SQL
- Snowflake
- DataCamp
- GitHub

## Analysis

### 1. Most Popular Transport Types

Used SQL to calculate the total number of passenger journeys for each transport type and rank them from most to least popular.

**Finding:** Buses recorded the highest total number of journeys in the dataset.

### 2. Emirates Airline Cable Car Popularity

Identified the five month-and-year combinations with the highest passenger journey totals for the Emirates Airline cable car.

### 3. Least Popular Underground & DLR Years

Identified the five years with the lowest total passenger journeys on the Underground and DLR.

**Finding:** 2020 recorded the lowest passenger journey total, likely reflecting the impact of the COVID-19 pandemic and associated travel restrictions.

## SQL Skills Demonstrated

- Filtering data using `WHERE`
- Aggregating data using `SUM()`
- Grouping records using `GROUP BY`
- Sorting results using `ORDER BY`
- Limiting results using `LIMIT`
- Handling missing values using `IS NOT NULL`
